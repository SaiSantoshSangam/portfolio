# Sangam Sai Santosh — AI Portfolio

## Files
- `index.html` — portfolio page and content
- `style.css` — responsive dark AI-inspired visual design
- `main.js` — mobile navigation, reveal animations, email copy interaction
- `Sai_Santosh_Resume.docx` — résumé download linked from the page

## Run locally
Open `index.html` in a browser. Google Fonts requires an internet connection; the site itself has no build step or framework dependency.

## Before publishing
- Confirm the LinkedIn URL in `index.html` is the exact public profile URL you want.
- The résumé is linked as a DOCX download. Convert it to PDF and update the link if you prefer a browser-friendly résumé.
- Project metrics are presented as provided in the résumé; keep them only if you can confidently explain their measurement and context in interviews.
